## 🚗 Car Race Game

A fun console-based car racing game built in C++.

### Features
- 🎮 Move car left/right to avoid enemies
- ⏸️ Pause & Resume anytime
- 🔄 Restart without going to menu
- 📈 Score tracking
- 💥 Improved collision detection

### Controls
| Key | Action |
|-----|--------|
| `A` | Move Left |
| `D` | Move Right |
| `P` | Pause / Resume |
| `R` | Restart |
| `ESC` | Back to Menu |

### How to Run
```bash
# Compile
g++ car_game.cpp -o car_game

# Run
./car_game
```
